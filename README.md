# MoreImg

当前 GitHub 分支是可直接运行的静态发布包，只保留页面入口、构建产物、字体和页面实际加载的第三方运行库。源码、测试、文档、截图和构建脚本保留在本地维护，不参与发布。

## 运行

使用任意静态文件服务器预览，例如：

```bash
python3 -m http.server 4187
```

打开 <http://127.0.0.1:4187/>。

运行文件：

- `index.html`：页面入口
- `app.js`：浏览器运行逻辑
- `styles.css`：页面样式
- `vendor/`：React、ReactDOM、Lucide 图标和 HTML 导出运行库
- `fonts/`：中文导出字体

API 请求由浏览器直接发送到设置中填写的 HTTPS 接口。接口必须允许 GitHub Pages 当前域名跨域访问；图片接口应优先返回 `b64_json`，或确保返回的图片 URL 允许跨域读取。API Key、历史记录、图片和运行日志统一保存在浏览器 IndexedDB 中，不写入仓库。

## 注意

GitHub Pages 只提供静态文件，不包含后端代理。需要文本或图片接口时，请使用允许跨域访问的 HTTPS 接口；若供应商不支持 CORS，需要在供应商侧开启，或另行部署线上边缘代理。

本地工作区仍保留完整源码，可在 `src/` 中修改后运行 `node build.mjs` 重新生成发布文件。发布分支会通过 `.gitignore` 自动忽略源码、测试和设计资料，避免再次上传非运行文件。
