## 提前断流诊断

连续验收前的一次诊断请求约 80 秒后只返回半截 JSON。根因是 SSE 连接在没有正常完成标记时结束，原读取器仍将已收到的文本交给 JSON 解析。实现已增加流完成标记检查，此类静默断流现在会明确报“流式响应提前结束”，不再伪装成普通 JSON 格式错误。修复后三次连续验收通过。
